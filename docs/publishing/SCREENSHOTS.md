# Store Screenshots & Visual Assets

## 1. Overview

High-converting Play Store screenshots are essential for ASO. Each app showcases its core value propositions through formatted screenshots with device framing and persuasive callouts.

---

## 2. Screenshot Requirements

- **Aspect Ratios**: 16:9 or 9:16 (minimum 1080x1920 or 1080x2400).
- **Quantity**: Minimum 4, recommended 6-8 per app.
- **Narrative Structure**:
  - Slide 1: Hero tool / primary differentiator (e.g. "Fast, Clean Calculator & Currency Converter").
  - Slide 2: Feature group 1 (e.g. "EMI & Financial Calculators").
  - Slide 3: Feature group 2 (e.g. "All-in-One Unit Converter").
  - Slide 4: Offline & Privacy guarantee ("100% Offline & Private").
  - Slide 5: Dark Mode & Clean UI ("Sleek Dark Mode Design").

---

## 3. CURRENT vs TARGET vs GAP

### CURRENT
- `store/screenshots/phone` and `store/screenshots/tablet` folders defined in all 8 apps.

### TARGET
- Automated screenshot capture using Maestro or Detox e2e test runners.
- Framed screenshot generator CLI to overlay title text and phone mockups automatically.

### GAP
- Screenshot automation pipeline to be set up when apps reach feature-complete beta status.
